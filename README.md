
# NOVA - AI Productivity Platform

A modern, fully responsive company landing page built for the Front-End Development Intern Assignment.

## Project Description
NOVA is a fictional AI-powered productivity platform that helps teams manage projects, automate repetitive tasks, and collaborate efficiently. This landing page is designed to look like a professional modern SaaS website.

Tagline: Build Better. Work Smarter.

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Flexbox and CSS Grid for layout
- Media Queries for responsive design
- To make it responsive i use Gemini AI.

## Features / Sections Implemented
- Navigation Bar with Hamburger Menu
- Hero Section
- Trusted By / Company Logos
- Features Section - 8 features
- Statistics Section
- Pricing Section - 3 plans
- Testimonials - 3 reviews
- FAQ Section - 5 questions with Accordion
- Final CTA Section
- Footer

## Required Interactions
- Responsive Navigation
- Mobile Hamburger Menu
- Smooth Scrolling
- FAQ Accordion
- Button Hover Effects
- Card Hover Effects
- Working Navigation Links
